# 洛雪原生液态玻璃版 v2 设计定稿（视觉 + 动效与触控反馈规范）

> 基准参考：Apple Music Android 测试版（用户提供的 4 张详情页截图）+ MeiloX（iOS 26 液态玻璃架构与播放页/导航/设置）+ 苹果原生 HIG 物理动效与触控反馈体系。
> 目标端：Android 12+（一加 7 Pro ColorOS 12 / SDK 31），Kotlin + Jetpack Compose + Haze 1.1.1 + Palette + Media3。

## 一、核心视觉定稿（对齐设计稿 sheet_a & sheet_b）

1. **详情页（歌单 / 榜单 / 专辑 — 全出血杂志沉浸风）**
   - 封面全宽顶到状态栏边缘（Full-Bleed），使用 `Palette` 提取封面主色/深色（`darkMuted` / `darkVibrant` / `dominant`），底边多层平滑渐变羽化进整页背景，彻底消除白底块与硬切灰带。
   - 顶栏采用轻透悬浮玻璃圆钮（左 `<` 返回，右 `搜索 + 更多` 胶囊），上滑时顶部渐显柔焦氛围毛玻璃栏并浮现歌单标题/副标题。
   - 居中极简操作三件套：左半透暗圆「随机」+ 中纯白高对比胶囊「▶ 播放」+ 右半透暗圆「收藏 / 下载」。
   - 简介限 2 行配右下角渐隐「更多」展开；曲目直接铺在沉浸底色上，极细左缩进分割线（`0.5dp`）+ 序号（热门曲目左侧圆点）+ 极简 `...` 图标，无多余白底卡片与红底标签。
   - 详情页底部 MiniPlayer 自动融入当前页面沉浸暗透玻璃风格。

2. **全屏播放页**
   - 100% 不透明动态流光背景（阻断底层内容透穿），多团封面提取主色缓慢流动并在切歌时 `650ms` 跨色融合。
   - 大圆角封面、细胶囊进度条、极简歌词 / 循环 / 待播队列三底钮。
   - 音质选择与更多操作采用 **iOS 26 液态玻璃气泡菜单（LiquidPopoverMenu）**，替代笨重全宽底部弹窗。

3. **主导航底座（iOS 26 悬浮双层液态玻璃）**
   - 左侧 4 项悬浮玻璃胶囊（资料库 / 发现 / 排行 / 设置）+ 右侧独立圆形「搜索」玻璃钮。
   - 双层玻璃增强 Haze 模糊半径与边界高光描边（顶边内发光 + 轻投影），解决浅色模式下底层文字发灰透穿问题。
   - 发现页 / 歌单广场：大标题 + 右上角音源玻璃气泡切换 + 横滑大号海报卡 + 极简无卡片曲目行。

4. **设置页**
   - iOS 分组圆角卡片 + 极细左缩进分隔线 + 液态玻璃选项气泡，完整适配浅色与深色双模式。

## 二、Apple Music 级动效与触控反馈设计系统（全链路强制标准）

> **核心原则**：禁用 Android 默认僵硬线性过渡与大面积扩散 Material Ripple；所有交互由**物理弹簧（Spring）+ 触觉微震动（Haptic）+ 液态玻璃高光反馈**共同驱动，全链路 60/120fps 运行于 `graphicsLayer`（避免布局阶段重测卡顿）。

### 1. 统一物理弹簧 Tokens（`LiquidMotion.kt`）
| Token | 参数 | 用途 |
| --- | --- | --- |
| `SpringSnappy` | `damping = 0.78f, stiffness = 520f` | 按钮按压回弹、开关、胶囊滑块、气泡菜单弹出 |
| `SpringGentle` | `damping = 0.86f, stiffness = 320f` | 页面推入/返回、MiniPlayer↔全屏展开、搜索栏变形 |
| `SpringBouncy` | `damping = 0.58f, stiffness = 420f` | 播放/暂停封面呼吸缩放、红心收藏跳动、切歌反馈 |
| `SpringFluid` | `damping = 0.92f, stiffness = 220f` | 歌词滚动聚焦、流光背景色相渐变、主题色切换 |

### 2. 全局触摸与点击视觉反馈（`LiquidTouch.kt`）
1. **玻璃按钮 / 胶囊 / 圆形图标（`Modifier.liquidPress`）**
   - 取消 Material 默认黑灰水波纹（`indication = null`）。
   - 按下瞬间：弹簧缩放至 `0.92f`（大按钮 `0.96f`）+ 表层叠加一层液态高光增亮（specular highlight `+14%` 白色柔光）+ `HapticFeedbackType.TextHandleMove` 轻震。
   - 抬手后按 `SpringSnappy` 弹性复位，高光在 `180ms` 内柔滑消散。
2. **海报大卡 / 封面方卡**
   - 按下整体缩至 `0.965f` + 封面叠加极轻压暗/微光层，不卡顿滚动手势（仅在有效按压态激活）。
3. **曲目列表行（`TrackRow`）**
   - 按住时整行在 `10dp` 圆角内浮现 Apple Music 标志性的柔和半透明高亮底色（深色 `white@10%` / 浅色 `black@6%`）+ 极微 `0.988f` 按压缩放，取代刺眼水波纹。
   - 当前播放行显示动态跳动 3 柱音频指示器；暂停时音柱平滑回落静止。
4. **播放控制三键（上一首 / 播放暂停 / 下一首）**
   - 按下图标缩至 `0.84f`，同时背后即时浮现 **48dp 半透明柔焦圆形光晕**（Apple Music 标志性按键光圈），松手光圈微扩淡出、图标弹性回弹。
   - 播放/暂停图标切换采用 `AnimatedContent` 缩放+淡入形变。
5. **进度条（`LiquidScrubber`）**
   - 常态为 `4dp` 细胶囊；手指按下瞬间弹簧增粗至 `8dp` + 进度轨道高亮发光 + 时间数字微亮放大 + 触感反馈；松手弹簧收细回 `4dp`。
6. **收藏红心**
   - 点赞时执行 `1.0 → 0.78 → 1.24 → 1.0` 弹性跳动动画 + 轻扩散光环 + 震动反馈。

### 3. 核心页面与组件级过渡动画
1. **详情页滚动联动（Scroll-Driven Choreography）**
   - **下拉过拉（Overscroll Stretch）**：继续下拉时全出血封面随拉距阻尼放大。
   - **上滑折叠（0 → 260dp 连续插值）**：封面视差慢速上移（`0.45x`）并渐隐、顶部 Haze 柔焦氛围条渐显、顶栏居中标题与副标题平滑上移淡入，全程连续无突变、无灰带。
2. **MiniPlayer ↔ 全屏播放页（连续手势 + 封面共享形变）**
   - 点击或上拉 MiniPlayer 展开全屏：背景平滑暗化，封面按弹性曲线从 `44dp` 过渡展开至大封面，标题与控制区错峰（stagger）浮现。
   - 全屏播放页支持**任意区域下拉跟手关闭**：实时联动整体位移、边缘圆角从 `0dp → 32dp`、缩放 `1.0 → 0.92`、背景透明度渐变；松手超阈值顺滑收回，否则弹性复位。
3. **全屏播放页：播放/暂停封面呼吸动效**
   - **播放中**：封面 `1.0x` + 封面主色深邃柔光阴影。
   - **暂停时**：封面以 `SpringBouncy` 缩至 `0.82x`，阴影同步收拢变浅。
4. **全屏播放页：三视图平滑切换（封面 ↔ 歌词 ↔ 待播队列）**
   - 切至歌词/队列时，大封面平滑缩移为顶部左侧 `48dp` 迷你头部信息栏（`AnimatedContent` + 共享位移动画），底部内容由下柔和浮现。
   - **逐行歌词动效**：当前行放大加粗高亮 + 轻微上浮弹簧；非当前行随距离渐变透明度与轻度柔焦（Android 12+ `blur`）；点击任意行带圆角高亮按压反馈并弹簧跳转。
5. **底部悬浮 Dock + 独立搜索圆钮变形**
   - 4 Tab 切换：玻璃高亮胶囊指示器按 `SpringSnappy` 弹性滑行（滑行中轻度横向拉伸形变），选中图标弹性微跳；页面切换采用轻缩放交叉淡入（`scale 0.985 → 1.0 + fade`）。
   - 点右下角搜索圆钮：左侧 4-Tab Dock 收缩淡出，搜索圆钮横向弹性延展成全宽底部玻璃搜索输入框，右侧平滑浮现圆形 `×` 玻璃按钮。
6. **页面导航推入/返回（iOS 风格层次过渡）**
   - 进入详情页：新页从右侧滑入（`+100% → 0%`），下层页同步向左微退（`0% → -22%`）并轻微压暗遮罩；返回时反向平滑还原。
7. **液态玻璃气泡菜单（`LiquidPopoverMenu`）**
   - 从触发按钮锚点以 `TransformOrigin` 弹性展开（`scale 0.84 → 1.0 + alpha 0 → 1` + 实时 Haze 模糊），关闭时反向收拢。
8. **MiniPlayer 跟手滑动切歌**
   - 左右滑动曲目区带阻尼跟手位移，过阈值触感反馈切歌，封面与氛围色平滑过渡。
